## Building

This is a [Hugo](https://gohugo.io/) site using the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme.

```bash
# Clone with submodules
git clone --recurse-submodules https://github.com/npcomplete777/o11y-alchemy.git

# Run locally
hugo server -D

# Build
hugo --minify
```
